JM DIGITAL OFFICE — v1.4.0 (Rental Manager Enhanced) — GITHUB UPLOAD INSTRUCTIONS
==================================================================================

This folder contains everything needed to upgrade your live site to v1.4.0.
Only the Rental Manager module has new features in this release — WBCYN
Registrar, Clinic Manager and Trust Manager are unchanged and will keep
working exactly as before.

Steps:

1. Open the GitHub repository.
2. Click "Add file".
3. Click "Upload files".
4. Drag all contents of this folder into the upload box
   (index.html, manifest.json, service-worker.js, sw-update.js,
   launcher.js, launcher.css, coming-soon.html, .nojekyll, icons,
   wbcyn, clinic, trust, rental).
5. Commit message:
   Upgrade Rental Manager to v1.4.0
6. Click "Commit changes".
7. Wait for the green GitHub Pages deployment (check the Actions tab or
   Settings → Pages for the green checkmark, usually 1–2 minutes).
8. Reload the iPhone website (or any browser).
9. Reinstall the Home Screen app only if the old version remains cached
   after reloading twice — a "New version available. Reload?" banner
   should normally appear and update the app in place, so this is
   usually not necessary.

What's new in v1.4.0 (Rental Manager only):
- WhatsApp reminders for tenants (rent, electricity, combined bill,
  agreement expiry, deposit settlement, general acknowledgement)
- Professional printable receipts (rent, electricity, combined,
  deposit, deposit refund) + Receipt History
- Monthly Billing Centre for batch bill generation with duplicate
  and paid-bill protection
- Occupancy Overview with summary cards and filters
- Analytics section with income/expense/occupancy charts (collapsible)
- Monthly Profit & Loss report with CSV export
- Enhanced backup and restore (Full / Property / Settings / Financial)
  with a Backup History log
- Smarter dashboard alerts with priority tiers and snooze

All existing properties, tenants, rent records and electricity records
are preserved automatically — no data is lost or reset by this update.
