JM DIGITAL OFFICE — v1.3.0 (Rental Manager) — GITHUB UPLOAD INSTRUCTIONS
=========================================================================

This folder contains EVERYTHING that needs to be uploaded to GitHub to
activate Rental Manager on your live site. Just follow these simple steps:

1. Open your GitHub repository in a web browser.

2. Click "Add file" (top right of the file list), then click "Upload files".

3. Open THIS folder on your computer and select everything inside it
   (all files and all folders: index.html, manifest.json,
   service-worker.js, sw-update.js, launcher.js, launcher.css,
   coming-soon.html, icons, wbcyn, clinic, trust, rental).
   Drag all of it into the GitHub upload box.

4. In the "Commit message" box at the bottom, type:
   Activate Rental Manager v1.3.0

5. Click the green "Commit changes" button.

6. Wait about 1–2 minutes for GitHub Pages to finish deploying
   (you'll see a green checkmark next to your commit, or you can check
   under Settings → Pages, or the "Actions" tab, for a green deployment).

7. On your iPhone (or any browser), refresh the JM Digital Office website.

8. If the Rental Manager card still shows "Coming Soon" after refreshing,
   simply reload the page a second time — a "New version available.
   Reload?" message should appear. Tap Reload.

9. You only need to remove and re-add the Home Screen app icon on your
   iPhone if step 8 does not resolve it after two refreshes. Normally
   this will NOT be necessary — the app updates itself in place.

That's it. WBCYN Registrar, Clinic Manager and Trust Manager are untouched
and will continue working exactly as before. Only the Rental Manager card
changes from "Coming Soon" to "Active", and a new Rental Manager module
becomes available at rental/index.html.
